# Setup Instructions - court.in

Panduan untuk menginisialisasi dan menjalankan proyek `court.in` di komputer lokal (Development Environment).

## Prasyarat (Prerequisites)
Pastikan sistem kamu sudah terinstal:
* **Node.js** (Versi 18 LTS atau terbaru)
* **PostgreSQL** (Berjalan di latar belakang)
* **Git**

## Langkah-langkah Instalasi

### 1. Kloning Repository
```bash
git clone [https://github.com/username-kamu/court.in.git](https://github.com/username-kamu/court.in.git)
cd court.in
